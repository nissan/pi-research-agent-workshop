# Loose Research Brief — Prompt-Only Run

## Summary

Grant-opportunity triage seems like a useful agent idea because consultants repeat similar research steps and clients want concise recommendations.

## Findings

- The task has repeated inputs and outputs.
- Consultants could save time.
- A specialized agent might become a paid offering.

## Recommendation

Build a pilot and see whether users like it.

## Limitations

This loose run is intentionally under-specified. It does not prove source quality, tool use, or output boundaries.
