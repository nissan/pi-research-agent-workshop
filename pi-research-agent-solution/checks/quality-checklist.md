# Quality checklist

Before calling the specialist agent monetizable, check:

- [ ] It solves a repeatable problem.
- [ ] It has a clear target buyer.
- [ ] It accepts structured input.
- [ ] It produces a predictable output.
- [ ] It separates facts, assumptions, and recommendations.
- [ ] It has a quality or evidence check.
- [ ] It can produce proof of completion.
- [ ] Another agent could consume its output without a meeting.
- [ ] It avoids secrets, private keys, and unnecessary personal data.
