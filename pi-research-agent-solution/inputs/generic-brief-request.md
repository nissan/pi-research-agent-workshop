# Generic brief request

## Topic

Should a boutique consulting firm create a specialized AI research agent for grant-opportunity triage?

## Audience

A small consulting team that advises startups and grant-funded innovation teams.

## Decision question

Is this a repeatable enough workflow to package as a specialist agent that other agents or operators would pay to use?

## Required output

Produce a concise decision brief with:

- executive summary;
- 4–6 key findings;
- evidence notes;
- risks/uncertainties;
- recommended next action;
- open questions.

## Constraints

- Use only the source notes and participant-provided additions.
- Separate fact, assumption, and recommendation.
- Do not invent citations.
