# Skill: Grant fit triage

Use this skill when evaluating a grant opportunity for a startup or innovation team.

## Steps

1. Check eligibility certainty.
2. Check deadline practicality.
3. Check required documents and partner dependencies.
4. Check matched-funding requirements.
5. Check reporting/admin burden.
6. Compare likely funding value against application effort.
7. Recommend apply, monitor, or skip.

## Output addition

Add a section called `Grant fit triage` with:

- eligibility certainty;
- execution risk;
- admin burden;
- funding-to-effort rating;
- recommendation.
