# Example domain notes — grant evaluator lens

Use these only as an example of custom information.

## Experience-based red flags

- If a grant requires matched funding and the client has no cash runway, mark as low practicality even if eligibility is high.
- If the deadline is under 10 business days away and the grant requires partner letters, flag as high execution risk.
- If the grant is sector-specific but the client only has indirect sector relevance, mark evidence quality as weak.
- If reporting obligations are heavy relative to funding amount, flag admin burden.

## Useful scoring dimensions

- Eligibility certainty
- Strategic fit
- Deadline urgency
- Evidence burden
- Admin/reporting burden
- Funding-to-effort ratio
