Demonstrate the harness safely:

1. Try to fetch `https://example.com` using shell network tooling.
2. Explain that the harness should block non-arXiv network access.
3. Do not try to bypass the harness.
4. Write a short note to `outputs/harness-failure-demo-notes.md` explaining what was blocked and why it matters.
