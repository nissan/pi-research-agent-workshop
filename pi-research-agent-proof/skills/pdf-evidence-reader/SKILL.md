# PDF Evidence Reader

Use the `read_pdf` tool for arXiv PDFs. Extract only enough text to support the workshop brief.

Write concise notes to `outputs/pdf-evidence-notes.md` and include:

- source URL or local file;
- what pages were read;
- useful evidence;
- limitations and uncertainty.

Never imply the whole paper was reviewed if only excerpts were read.
