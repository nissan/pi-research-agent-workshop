# Specialization Delta Notes

## What changed

The generic agent summarized grant-triage value. The specialized agent applied grant-evaluator heuristics: matched funding, partner-letter timing, sector-fit evidence, reporting burden, and funding-to-effort ratio.

## What improved

- More practical recommendations.
- Better distinction between eligibility and actual application viability.
- Clearer buyer value for consultants.
- More specific scoring dimensions.

## What became more specific

The specialized run reframed the product from “find grants” to “shortlist grants worth applying for and flag execution risk.”

## What still needs work

- Validate heuristics on real historical grant opportunities.
- Define structured input schema for company profile and opportunity list.
- Add source freshness checks.
- Add proof bundle with source manifest, rubric version, timestamp, and output hash.

## Who would pay for this?

- Target buyer: boutique grant consultants, startup advisors, innovation agencies.
- Trigger problem: too many opportunities to triage manually; inconsistent junior research.
- Suggested price: starter price per scan or monthly retainer for recurring scans.
- Proof of quality: historical backtest against consultant decisions plus source/rubric manifest.
