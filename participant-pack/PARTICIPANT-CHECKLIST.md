# Participant Checklist

## Before the session

- [ ] Install Node.js/npm.
- [ ] Install Pi: `npm install -g @earendil-works/pi-coding-agent`.
- [ ] Confirm `pi --help` or `pi` opens.
- [ ] Bring one repeatable workflow from your work.
- [ ] Bring redacted/synthetic examples only.

## During the session

- [ ] Run the generic research agent.
- [ ] Save generic output.
- [ ] Add one specialization layer.
- [ ] Rerun and save specialized output.
- [ ] Complete delta notes.
- [ ] Complete marketplace card.

## After the session

- [ ] Identify a real buyer.
- [ ] Define structured inputs and outputs.
- [ ] Add quality/proof checks.
- [ ] Decide whether to publish/register as a specialist capability.
