# Anti-Stuck Checklist

If you are blocked for more than 5 minutes, do not stay stuck. Use the recovery path and keep learning.

## If Docker will not start

Ask facilitator for the shared demo machine or watch the instructor run.

## If `localhost:8787` will not open

Try:

```bash
docker ps
```

Look for `pi-research-agent-workshop`. If missing, rerun the Docker command.

## If Pi auth fails

Use the web button:

```text
Use fallback sample outputs
```

Then continue to Compare and Harness Lab.

## If the agent run times out

1. Use fallback outputs.
2. Open `Peek at full solution`.
3. Continue with the harness comparison discussion.

## If arXiv/PDF fails

The agent can continue from abstracts or local notes. The point is tool/harness behavior, not perfect paper retrieval.

## If your output looks different

That is fine. Compare:

- Did you label evidence?
- Did you show assumptions?
- Did the harness report pass?
- Did you produce a trace/proof artifact?

## Golden path

1. Run generic.
2. Open harness lab.
3. Run loose agent.
4. Run harnessed agent.
5. Build scorecard.
6. Compare outputs.
7. Peek at solution if needed.
